📋 Como Integrar em Seu Projeto

Para usar este widget em seu projeto, siga os passos abaixo:

1. Inclua o VLibras no seu HTML:

<!-- VLibras Widget --> <div vw class="enabled"> <div vw-access-button class="active"></div> <div vw-plugin-wrapper> <div class="vw-plugin-top-wrapper"></div> </div> </div> <script src="https://vlibras.gov.br/app/vlibras-plugin.js"></script> <script> new window.VLibras.Widget('https://vlibras.gov.br/app'); </script>

2. Implemente o reconhecimento de voz:

// Configurar Web Speech API const recognition = new (window.SpeechRecognition || window.webkitSpeechRecognition)(); recognition.continuous = true; recognition.interimResults = true; recognition.lang = 'pt-BR'; // Processar resultados recognition.onresult = function(event) { let transcript = ''; for (let i = event.resultIndex; i < event.results.length; ++i) { transcript += event.results[i][0].transcript; } document.getElementById('transcript').textContent = transcript; }; // Iniciar reconhecimento function startRecording() { recognition.start(); }

3. Integre com VLibras:

function sendToVLibras(text) { // Criar elemento temporário com o texto const tempElement = document.createElement('div'); tempElement.textContent = text; tempElement.setAttribute('vw', ''); tempElement.style.position = 'absolute'; tempElement.style.left = '-9999px'; // Adicionar ao DOM e simular clique document.body.appendChild(tempElement); tempElement.click(); // Remover após um tempo setTimeout(() => { document.body.removeChild(tempElement); }, 1000); }

⚠️ Requisitos Importantes:

  • HTTPS: Necessário para Web Speech API
  • Permissões: Usuário deve permitir acesso ao microfone
  • Navegadores: Melhor suporte no Chrome e Firefox
  • Internet: Conexão necessária para VLibras e reconhecimento
